## Condiciones para Finalización

### Diseño de Prototipos
- [ ] Diagrama de circuito básico realizado en KiCad.
- [ ] Listado de entradas y salidas del circuito (señales, tensión).
- [ ] Simulación básica en LTSpice (o derivados), con imágenes de resultados.
- [ ] Componentes definidos con especificaciones mínimas en el diagrama.
- [ ] Lista de componentes requeridos.
- [ ] Breve descripción del funcionamiento del circuito, con figuras orientativas.
- [ ] Diseño de PCB con componentes THT (en lo posible), para ayudar con la disposición en placa de islas perforadas.
- [ ] Nombre de prototipo característico.
- [ ] Determinación del uso de disipadores (señalizado en el esquemático).
- [ ] Hoja de cálculos.

### Confección de Prototipo
- [ ] Realizado en una placa de islas perforada.
- [ ] Soldadura con estaño.
- [ ] Verificación de cortocircuitos.
- [ ] Utilización de componentes THT, en lo posible.

### Pruebas de Laboratorio
- [ ] Hoja de ruta para añadir a la carpeta de campo, con:
  - Fecha y hora
  - Ubicación
  - Integrantes
  - Condiciones del ambiente
  - Componentes utilizados
  - Experimentos realizados
  - Descripción de resultados
- [ ] Nombre del prototipo probado.
- [ ] Fotos de los resultados.
